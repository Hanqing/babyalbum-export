## 实测到的 App 行为（影响设计）

- 批量下载页路径：首页「进入设备」→ 设备页相册卡片 →「时光相册」右上角 →「全部照片」→「精彩瞬间」。
- 编辑模式下每个日期组有整组勾选框；点勾选框本身才生效。勾选数量没有上限（实测 153 张仍可继续）。
- 底部“删除”（左半）和“下载”（右半）紧挨着；工具只点右半并先核对文字和 ID，App 版直接调用按钮自身的点击动作。
- 下载很快：36 张约 6 秒落盘。真正的耗时在勾选和翻页。
- “已下载”的判断依据是 `DCIM/Camera/海马爸比` 里有没有同名文件，结果缓存在 App 进程里；强制停止后重新判断。
- 同一照片再次下载会生成“ (1)”副本，内容与原文件逐字节相同；说明下载拿到的是服务器上的同一份文件。
- 照片没有 EXIF；文件名是 Unix 时间戳，`_NGT` 为夜间红外照，按东八区解释。
- 下载时 App 会弹短暂的加载框，下载后列表会重新加载，编辑按钮短暂消失；两版都改为“等它消失再继续”，不按返回键。

## 测试中踩到并已修复的问题

- **vivo 跨应用提醒**：App 打开海马时，vivo 弹出“宝宝相册导出想要打开海马爸比”。这是用户本人的授权，App 只在进度条提示“请点始终打开”并等待 45 秒，不代点。测试机上已选“始终打开”。
- **无障碍“活动窗口”过时**：服务只订阅海马的事件，系统记录的活动窗口会停在已经退到后台的海马窗口上，导致读到旧界面。改为读取当前获得焦点的应用窗口。
- **控件暂时缺失被当成安全问题**：列表重载时编辑按钮短暂消失，原逻辑直接安全停机。改为重读界面再试；安全停机只留给危险控件、删除键附近和非海马窗口。
- **列表滚动位置被保留**：App 会记住上次的滚动位置；每批开始前先回到列表顶部。
- **测试注意**：uiautomator 抓界面会暂停其他无障碍服务，测 App 时只看日志、不抓界面。vivo 每次通过 USB 安装都要在手机上确认风险提示。

## 桌面版

- 只用 Python 标准库 + adb；命令 `doctor / export / sync / archive / report / gui`。
- 每张照片核对手机端 SHA-256、大小和 JPEG 结构后原子入库；同一内容只存一份；账本为 SQLite。
- 报告分“搬运完整性 / 来源覆盖 / 质量与限制”；`archive` 生成写入拍摄时间（+08:00）的按月副本。
- 安全：导航白名单、拒点含“删除”的控件、勾选框遮挡检查、下载点位远离删除、陌生页面暂停。
- 测试：19 项单元测试（含真机界面样本）；`tools/test_queue.py` 在手机上造真实的待下载队列并在测后逐张核对复原。

## 独立 App

- 无障碍服务只接收海马爸比的事件，只在点“开始导出”后运行；顶部进度条可随时停止；熄屏自动暂停。
- 流程与桌面版一致；读界面几乎无延迟，翻页用“滑动后停住再抬手”的手势避免惯性跳组。
- 不依赖 Gradle：`build.sh` 直接调用 aapt2、javac、d8、zipalign、apksigner。

## 全量基准

测试方法：把手机上 2,515 张照片挪到临时目录（先记录 SHA-256），强制停止海马 App，让照片重新变成“未下载”；跑完后逐张核对重新下载的文件与原文件逐字节一致，再删除临时副本。两个版本各跑一遍，手机最终保持原样。

| 版本 | 总用时 | 勾选 | 下载 | 结果 |
| --- | --- | --- | --- | --- |
| 原型（2026-10-24） | 68.5 分钟 | — | — | 2,514 张，143 批 |
| 桌面版 | 20 分 44 秒 | 961 秒 | 168 秒 | 2,515 张，13 批；电脑端逐张校验，失败 0 |
| 独立 App | 约 11 分钟（166 秒 + 490 秒） | 427 秒 | 130 秒 | 2,515 张，13 批；第一轮停在 614 张后修复并续传 |

- 两个版本都已验证：重新下载的 2,515 张与原文件 SHA-256 全部一致。
- 瓶颈是勾选：桌面版每次读界面约 3 秒（共 228 次）；App 读界面几乎即时，所以快一倍。下载本身每 200 张约 10 秒。
- 续传可用：App 第一轮中断后，再次开始从 2026-04-25 接着下载，没有重复。

电脑上的正式归档：`~/Pictures/海马爸比相册归档`（原始文件 2,515 张 + 按月份带拍摄时间的副本 + 导出报告，共 1.0 GB）。原来的 `海马爸比时光相册_本次导出` 未改动，可自行删除。

## 还没覆盖

- Windows 实机、其他品牌手机、海马爸比其他版本、纯血鸿蒙（不运行安卓 App，无 ADB）。
- 桌面版打包成双击即用的安装包（内置 Python 与 adb）；App 的正式签名与分发渠道。
- 照片是否等同摄像头原图：已证明下载内容稳定一致，尚未与摄像头源文件比对。
