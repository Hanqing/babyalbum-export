安全规则

只点该点的，
“删除”碰都不碰

  • 只点白名单

    只点导航白名单里的控件和日期勾选框；文字含“删除”的控件一律不点。

  • 离“删除”远远的

    “删除”和“下载”紧挨着。桌面版只点“下载”远离“删除”的一侧，点之前先核对两个按钮的文字和 ID；App 直接调用“下载”按钮自己的点击动作。

  • 看不懂就停

    不认识的页面、锁屏、断线、连续没有进展，都会暂停，等你处理好再接着来。

  • 照片只进不出

    不删除、不移动手机上的照片；不联网，不上传。

开始使用

三步就能开始

安卓 App

  1. 1

    下载安装

    下载 APK 并安装。手机提示“来源不明”或“有风险”时，确认继续安装。

  2. 2

    开启无障碍服务

    打开「宝宝相册导出」，点“去开启”，在无障碍设置里打开它。开关是灰色的话，先在应用详情右上角菜单里点“允许受限设置”。

  3. 3

    开始导出

    点“开始导出”，保持亮屏、不要操作手机。顶部黑条显示进度，可以随时停止。

桌面版

  1. 1

    打开 USB 调试

    设置 → 关于手机 → 连续点“版本号”7 次；在开发者选项里打开“USB 调试”，连上电脑后在手机上点“允许”。

  2. 2

    准备电脑

    需要 Python 3.9+ 和 adb。Mac 可以用 brew install android-platform-tools，也可以把 Google 的 platform-tools 解压到程序目录里。

  3. 3

    双击启动

    Mac 双击「相册导出助手.command」，Windows 双击「相册导出助手.bat」，在打开的网页里点“开始导出”。

你可能想知道

开始前，
了解这些

这是海马爸比官方的工具吗？

不是。这是一个独立的开源项目，和海马爸比及其开发商没有关系。它只是替你在官方 App 里点“勾选”和“下载”；登录和下载都在官方 App 里完成。

会不会删掉我的照片？

不会。两个版本都只点导航白名单里的控件和日期勾选框，文字含“删除”的控件一律不点，遇到不认识的页面就暂停。工具也不会删除或移动手机上的任何照片。

下载到的是原图吗？

拿到的是官方 App 提供的照片文件（实测为 2560×1440 的 JPG）。同一张照片重复下载，文件逐字节相同；但还没有和摄像头里的源文件比对过，所以不敢说一定等同于摄像头原图。

为什么要开无障碍服务？

安卓 App 要靠它读取海马爸比的界面并点击。服务只接收海马爸比 App 的事件，只在你点“开始导出”后操作；不读取照片内容，不联网。导出结束后可以随时关掉。

为什么不直接在电脑上装海马爸比？

海马爸比在电脑和手机上同时登录会互相踢下线。桌面版通过数据线操作手机上已经登录的 App，不需要重新登录。

支持哪些手机？

已实测：vivo V2133A，Android 14，海马爸比 3.4.2。其他安卓手机和版本大概率能用，遇到不认识的页面会暂停，不会乱点。纯血鸿蒙不能运行安卓 App，也没有 adb，暂不支持；iPhone 也不支持。

中途断了怎么办？

再点一次“开始导出”就行。进度以手机上已经下载的照片为准，下过的不会重复下载。

照片的拍摄时间对吗？

原图里没有拍摄时间信息，文件名就是拍摄时刻（Unix 时间戳，带 _NGT 的是夜间红外照）。桌面版的“按月份”副本按东八区写入了拍摄时间，导入相册后会按真实时间排序；原始文件保持不变。

安装时提示有风险，或者无障碍开不了？

从网页下载的 APK 不来自应用商店，手机会提示风险，确认安装即可。Android 13 及以上如果无障碍开关是灰的，到「应用详情 → 右上角菜单 → 允许受限设置」后再开。vivo 第一次会问是否允许打开海马爸比，请选“始终打开”。

Mac 双击启动时提示无法验证开发者？

右键点「相册导出助手.command」，选“打开”，再确认一次即可。也可以在终端里进入程序目录，运行 python3 -m album_export gui。

Windows 能用吗？

桌面版是跨平台的 Python 程序，Windows 上会自动查找 adb；部分手机需要先装厂商的 USB 驱动。目前还没有在 Windows 实机验证过，欢迎反馈。

收费吗？

免费，源码以 MIT 许可公开在 GitHub。遇到问题可以提交反馈。
